RhinoGraft

Every Rhino object is an entity.

Objects, layers, materials, block definitions: each one keyed by its Rhino GUID.

Every version is immutable.

An entity version is a manifest of named component blobs and references, addressed by its SHA-256 hash.

Commits cost only what changed.

A commit points to a Merkle tree. Edit one seat row and only its path is rehashed, so commits and diffs scale with the change, not the model.

No invalid snapshots. No silent overwrites.
